## 🌟 Overview

This portfolio is an engineering-first personal brand and interactive data laboratory designed for **Timothy John Chikereze**—a Data Analyst, Business Intelligence Specialist, and Computer Science graduate from the **Federal University of Technology, Owerri (FUTO)** and **TechBridge Data Analytics Fellow**.

Inspired by elite developer portfolios (like [toppinns.com](https://www.toppinns.com/)), this website elevates standard portfolio designs with custom 3D data projections, interactive query consoles, predictive KPI scenario modeling, and dynamic full-screen case study modals.

---

## 🚀 Key Features

* **Signature 3D Interactive Data Constellation Canvas**: Custom HTML5 Canvas 2D/3D projection engine rendering an interactive rotating sphere of data nodes and relational edges with inertia damping and pointer parallax.
* **Floating 3D Perspective Stat Cards**: Real-time cursor tracking cards highlighting audited revenue, records cleaned, and customer markets.
* **Spotlight Command Palette (`Cmd + K` / `Ctrl + K`)**: Instant keyboard modal to filter case studies, jump to sections, switch themes, or copy contact information.
* **The Data Analytics Laboratory**:
  * **Interactive SQL Query Playground**: Run live relational SQL queries across retail sales and workforce churn tables with instant sub-millisecond execution.
  * **Predictive Retention Scenario Modeler**: Interactive dual-slider simulator demonstrating the mathematical impact of employee satisfaction and workload capacity on turnover rates and recruitment cost savings.
* **Dynamic Case Study Overviews**:
  * **Workforce Retention & Attrition Intelligence**: Analysis of 11,991 records featuring high-resolution Power BI dashboard previews and DAX measures.
  * **Retail Sales Performance Capstone**: Audit of ₦42M+ gross revenue reconciling negative quantity anomalies and referential integrity errors.
  * **Global Customer Demographics Engine**: SQL queries segmenting 8,000 customers across 20 countries.
  * **Workforce Data Wrangling & Imputation Pipeline**: Normalizing messy data with statistical imputation.
* **Draggable 3D Tech Tag Cloud**: Interactive rotating sphere of core analytical tools (SQL, Power BI, DAX, PostgreSQL, Excel, etc.).
* **Instant Dual Theming**: Electric Cyan / Teal cyber-intelligence dark theme (`#080a0f`) with high-contrast light mode toggle.

## 💻 Local Development

### Prerequisites
* Node.js (v18+)
* `pnpm` (or `npm` / `yarn`)

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Hogwartsofweb3/Chikereze-DA.git

# Navigate to project directory
cd Chikereze-DA

# Install dependencies
pnpm install
# or: npm install

# Start development server
pnpm dev
# or: npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Typecheck and compile production bundle
pnpm build
# or: npm run build

# Preview production build locally
pnpm preview
# or: npm run preview
```
